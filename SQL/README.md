# SQL Analysis

This folder contains the SQL analysis performed on the SBA loan dataset.

The analysis covers:

- Portfolio performance and lending exposure
- Data quality and validation checks
- Sector and industry analysis
- Geographic and state-level analysis
- Borrower and business characteristics
- Loan characteristics and repayment outcomes
- Bank performance and risk analysis
- Default and loss-rate analysis
- Customer persona and cross-analysis
- Historical trends and risk insights

The SQL analysis was performed using **MySQL** and formed the analytical foundation for the Power BI dashboard and final business recommendations.
