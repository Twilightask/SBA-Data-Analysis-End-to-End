# Dataset

This project uses SBA 7(a) loan-level data for portfolio, risk, borrower, sector, geographic, and financial-loss analysis.

## Source

The original dataset is provided by the U.S. Small Business Administration (SBA).

[Official SBA Loan Approval Analysis Dataset](https://www.kaggle.com/code/kevinm6720/sba-loan-approval-analysis)

## Cleaned Dataset

The cleaned dataset used for the SQL analysis and Power BI dashboard is available here:

[Download Cleaned Dataset](https://drive.google.com/file/d/1szetfKxdfITN2BX7VGgSgb-qeihvgTmN/view?usp=sharing))

## Data Preparation

The dataset used in this project was cleaned and transformed before analysis. Key preparation steps included:

- Handling missing and inconsistent values
- Standardizing state and categorical fields
- Correcting date and currency formats
- Creating business, sector, employee-size, loan-term, and SBA-coverage categories
- Preparing the dataset for MySQL analysis and Power BI reporting

The full processed dataset is not included in this repository due to file-size limitations.
