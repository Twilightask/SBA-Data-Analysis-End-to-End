# Power BI Dashboard

This folder contains the Power BI dashboard developed for the SBA Loan Portfolio Risk & Lending Analytics project.

## Dashboard

The interactive Power BI report can be downloaded here:

[Download Power BI Dashboard (.pbix)](https://drive.google.com/file/d/1nGw3M25U6dwS63JK-6HkCjpIl_c4RfF9/view?usp=sharing)

The dashboard contains four analytical pages:

1. Portfolio Overview
2. Sector & Borrower Risk
3. State & Geographic Analysis
4. Loan & Borrower Risk

The `.pbix` file is hosted externally due to GitHub file-size limitations.
